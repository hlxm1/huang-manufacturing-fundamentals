# 第一章：机械制造概论

定位：印刷页 1–7；PDF 第 11–17 页。重点依据：p.3–6。本章偏概念，历史数据只代表原书出版时期。

## 核心判断

先确定制造任务、生产类型和工艺系统，再选设备和参数。单件最短加工时间并不等于整个生产系统的最佳方案。

## 系统框架与操作方法

### 生产系统 → 制造系统 → 工艺系统

- **生产系统**包含决策、计划管理与生产技术三个层次，还涉及研发、经营及外部市场环境。用它判断设备投资、产能和交货安排。
- **制造系统**关注毛坯制造、加工、装配、检验、储运；同时检查物质流、信息流、能量流。用它找在制品积压、等待与物流瓶颈。
- **工艺系统**由机床、刀具、夹具、工件组成。解释尺寸漂移、振动或效率不足时，逐项分析各环节及其相互作用，不能只归因于操作者。

这三个层次的边界不同：降低某道工序的切削时间，若同时增加换装、检验或等待，未必改善交付。

### 用生产纲领决定工艺投入（p.4–5）

1. 核实产品年产量 Q、每台所需零件数 n、备品率 a 和废品率 b。
2. 原书采用 `N = Qn(1+a)(1+b)`。a、b 在代入时取小数，如 2% 写成 0.02；原式及百分率口径见公式核验记录。
3. 综合零件大小、复杂程度和专业化程度判断单件、小批、中批、大批或大量生产；不能把某一件数门槛用于所有零件。
4. 再比较毛坯精度、机床布置、夹具投入、操作技能、装配方法和工艺文件详略。

| 生产情形 | 优先考虑 | 代价与约束 |
|---|---|---|
| 单件小批、对象常变 | 通用设备、通用工装、数控加工的柔性 | 单件准备与调整时间相对较高 |
| 中批、周期性轮换 | 兼顾柔性和效率，选择性采用专用夹具 | 必须核算换型与工装摊销 |
| 大批大量、对象稳定 | 高效专机或生产线、专用工装、稳定节拍 | 投资和产品变更成本较高 |

表为对原书表1-2的综合提炼，非逐格抄录。表1-1的数值分档须查原页，不能用 OCR 串行文本直接生成分类阈值。

### 制造方法选择（p.5–7）

先问零件材料、形状、尺寸与表面要求，再看批量和工厂条件。净成形或近净成形适用于减少材料损耗和后续切除量；切削加工用于获得规定几何形状、精度和表面质量；难加工材料或特殊几何可评估特种加工。

特种加工仍有各自适用条件：例如电火花要求工件导电，超声加工也存在工具与磨粒的机械作用。原书概括性的分类不能解释为所有特种加工对材料和作用力均无限制。

## 关键概念

- **生产纲领**：计划期内应生产的产品产量和进度计划，通常以年为单位。
- **生产批量**：一次投入或产出的同种产品或零件数量，不等于年产量。
- **生产类型**：按生产专业化与重复程度划分的组织和工艺特征。
- **净成形**：成形后无需加工或仅需少量加工即可成为可用零件的技术。
- **绿色制造**：把环境影响和资源效率纳入产品全生命周期。

## 改编练习：由需求估算零件纲领

以下数字为自编，按 p.4 方法演示，非原书例题。某产品年产 1000 台，每台用 2 件，备品率 2%，废品率按原书口径取 1%：

`N = 1000 × 2 × 1.02 × 1.01 = 2060.4 件/年`。

计划数量向上取整为 2061 件，再结合零件大小和生产组织判断类型。若“废品率”实际定义为投入件数中的报废比例，则为满足给定合格数应采用除以 `(1-b)` 的物料平衡，不能混用两个定义。

选择专用夹具前，进一步比较其年摊销、每批调整时间和节省的单件工时；仅凭 N 不能直接决定采购专机。

## 常见误区与检查

- 把生产纲领当批量：会误算换型次数与在制品。
- 只优化切削时间：可能把瓶颈转移到装夹、检验或物流。
- 把书中的“当前水平”当今天的行业上限：原书出版于 2011 年，历史数字需另查现状。
- 先买设备再论证工艺：应由零件要求和产能反推工艺与装备。

练习自查：能否说明自己的问题属于哪一级系统？生产纲领、生产批量和设备能力是否分别列出？
