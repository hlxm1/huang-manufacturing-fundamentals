# 第二章：金属切削原理

定位：印刷页 8–48；PDF 第 18–58 页。重点：p.8–14、21–42、44–47。

## 核心判断

把切削看成“变形和摩擦 → 力与热 → 磨损和质量”的耦合过程。调整参数时同时判断机床功率、工件刚度、刀刃强度、排屑、表面质量和换刀成本。

## 从运动到参数

主运动负责形成主要切削，进给运动使新材料不断进入。待加工表面、过渡表面、已加工表面是三个不同对象，分析刀面接触和受力时先画清它们。

下列关系已回看 p.9 原页。表内统一采用分钟制：

| 量 | 关系 | 单位和适用条件 |
|---|---|---|
| 切削速度 | `vc = πdn/1000` | d 为 mm，n 为 r/min，vc 为 m/min |
| 进给速度 | `vf = fn = fz·z·n` | f 为 mm/r，fz 为 mm/齿，vf 为 mm/min |
| 外圆车削背吃刀量 | `ap = (dw-dm)/2` | 直径与 ap 均为 mm |
| 切削层厚度与宽度 | `h=f·sinκr`，`b=ap/sinκr` | 直线主切削刃的外圆车削模型 |
| 切削层面积 | `A=h·b=f·ap` | mm²；最后一式为车削关系 |

若 n 改用 r/s，上式 vc 和 vf 就相应为 m/s、mm/s，不能只改单位标签。

## 几何角度：标注条件不等于工作条件（p.10–14、37–39）

- 基面 Pr、切削平面 Ps、正交平面 Po 构成正交平面参考系。角度须指明参考系、刃上测点与正负方向。
- **前角 γo**增大通常可减小变形和切削力，但削弱楔部强度和散热体积。粗加工、硬皮、冲击或断续切削应先保证刃口可靠性。
- **后角 αo**减小后刀面摩擦；过大会削弱刀刃。磨损体积寿命与径向尺寸寿命是不同约束。
- **主偏角 κr**改变厚度、宽度及力的分配。细长轴刚性不足时，增大主偏角有利于减小径向力；刀尖圆弧变大却可能增加径向负担。
- **刃倾角 λs**涉及排屑方向与刃口受力，不能只凭正负号脱离具体刀具图判断流屑。
- 大进给、车螺纹、接近中心切断、刀尖不等高或刀杆装偏，均会改变工作角度。工作后角不足时，继续增加进给可能转为挤压摩擦。

## 三变形区与切屑控制（p.14–21）

第一变形区以剪切滑移及加工硬化为主；第二变形区是切屑沿前刀面的摩擦和变形；第三变形区靠近后刀面与已加工表面，直接关联表层质量。

塑性材料可能出现带状、挤裂或单元切屑，脆性材料常形成崩碎切屑。用材料状态、切削厚度、速度和断屑槽共同控制切屑，不能把危险的长带屑当作加工优良的充分证据。

积屑瘤会改变实际刃形，脱落碎片又会损害表面和刀具。精加工出现不稳定表面时，检查积屑瘤、刃口状态和润滑，而非一味减速；原书实验中的速度区间只对应所列材料与刀具条件。

## 切削力、热与寿命的决策（p.21–35）

| 现象或目标 | 优先分析 | 为什么 |
|---|---|---|
| 校核主轴功率 | 主切削力 Fc 与 vc | 主切削功通常占主导 |
| 薄壁件变形或让刀 | 径向力 Fp、支承和装夹刚度 | 功率合格仍可能尺寸超差 |
| 刀具热磨损快 | vc、导热与冷却、材料匹配 | 通常 vc 对温度和寿命影响最显著 |
| 刃口突然破损 | 冲击、强度、振动、热冲击 | 破损不等于正常磨耗到寿命 |
| 自动线换刀损失大 | 换刀组织、刀具可靠性及寿命匹配 | 最短净切削时间未必带来最高产出 |

磨料磨损、粘结磨损、扩散磨损等机理可能并存。正常磨损曲线经历初期、正常和剧烈阶段，应在剧烈磨损前换刀；VB 磨钝界限随精度、刚度、材料及刀具而变。

已核验 p.25：忽略进给功率时，若 vc 用 m/s，`Pc≈Fc·vc/1000` kW；改用 m/min 则为 `Pc≈Fc·vc/60000`。电动机功率至少满足 `PE≥Pc/ηm`，还需实际转速处的扭矩和可用功率。

已核验 p.33：`vc·T^m=A`，只在其他条件和磨钝标准固定的实验范围内成立。A 和 m 需要对应材料、刀具和条件的数据；不可拿书中某一例的指数通用于所有加工。

## 合理选用切削条件（p.35–42）

1. 根据材料状态和工序目标选择刀具材料、几何与冷却方式。
2. 先在余量、刚度和功率允许范围内确定 ap。
3. 再按粗糙度、刃口和进给机构约束确定 f。
4. 最后依目标寿命和产品资料选择 vc；换算 n 后按机床档位或控制范围复核实际 vc。
5. 试切，记录尺寸、粗糙度、力/功率、切屑和磨损，逐项验证限制条件。

这是原书的一般选择次序，不表示精加工也应无条件取最大 ap、f。冷却液要在冷却、润滑、排屑、防锈间取舍；硬脆刀具断续加工还要控制热冲击。配液浓度应查现用产品说明，不能直接把教材示例变为生产配方。

## 磨削与砂轮（p.42–47）

磨粒作用包括滑擦、耕犁和形成切屑。磨削单位去除体积能耗高，径向作用和表面热损伤都应重点监测。

选择砂轮须同时写明磨料、粒度、结合剂、硬度、组织及尺寸/允许速度。**砂轮硬度是磨粒脱落难易，区别于磨料本身硬度。**硬工件通常要求砂轮较易自锐，但软而粘的材料也可能因堵塞而需要较软、疏松的砂轮；不能仅靠“工件硬选软轮”一句话完成选型。

### 原书标记例的紧凑重构（p.47）

原书以 `1—300×30×75—A60L5V—35m/s` 示范砂轮标记：平形；外径300、厚30、孔75 mm；棕刚玉 A；60粒度；硬度 L；组织5；陶瓷结合剂 V；最高圆周速度35 m/s。它是标记解读示例，不代表适合任意工件；订货时还需核对现行标记体系与厂家数据。

### 自编计算练习

外圆由52车至48 mm，一刀径向吃刀量为2 mm。按待加工直径52 mm、目标 vc=100 m/min，计算 n≈612 r/min；实际取600 r/min时 vc≈98.0 m/min。若 f=0.20 mm/r，则 vf=120 mm/min，A=0.40 mm²。尚不能据此断言工艺可行：Fc、刚度、粗糙度与刀具寿命均未核定。

## 常见误区与自查

- 把切削速度当转速、把每齿进给当每转进给。
- 只看刀具硬度，不看韧性、热稳定性及化学相容性。
- 追求最长寿命而忽略停机成本，或追求最高速度而忽略频繁换刀。
- 用提高进给掩盖钝刀和振动，导致热、力与表面损伤同步增加。

自查：每个经验系数是否有来源、单位和适用范围？实际转速、实际进给是否已回算？
