# 第5章 机床夹具设计原理

来源：印刷p.118–148 / PDF第128–158页。

## 核心判断

夹具先确定工件相对刀具和机床的位置，再在载荷下保持这个位置。把定位、夹紧、对刀/导引、夹具安装四条精度链分别检查，不能用“已经夹牢”代替定位证明。

## 六点定位：先列要求再数自由度（p.120–128）

空间刚体有三个移动和三个转动自由度。六点定位是六个按几何要求分布的等效约束，并非任意六处接触。

1. 画坐标轴并标明工序尺寸、位置要求和切削方向。
2. 从每条加工要求反推必须限制的自由度。
3. 给每个定位元件写出其独立限制的自由度；检查接触长度和支承点分布。
4. 合并约束，找缺失与重复。工序要求的自由度全部被限制才成立。
5. 考虑实际制造误差、毛刺、间隙和受力后接触变化。

| 状态 | 判据 | 处理 |
|---|---|---|
| 完全定位 | 六自由度均被限制 | 检查是否确有必要及有无重复约束 |
| 不完全定位 | 少于六个，但要求所需约束齐全 | 可以使用，同时保证受力稳定 |
| 欠定位 | 加工所需约束有遗漏 | 修改方案，不能靠偶然摩擦补救 |
| 过定位 | 同一自由度被重复限制 | 分析装配干涉/变形；解除冗余或证明精度与顺应性足够 |

典型3-2-1方案中：底面三个不共线支承限制垂直移动及绕两水平轴转动；侧面两个分开支承限制一个水平移动及绕竖直轴转动；端面一个支承限制最后一个移动。若点位重合或跨度太小，即使数量正确也可能不稳定。

## 定位元件选择

- 平面：固定/可调支承；毛坯或断续面考虑自位支承。自位支承的多个接触点通过浮动机构共同作用，不能按接触点数重复计算独立约束。
- 外圆：V形块、定位套、半圆套。短V形块通常限制两个自由度，长V形块还约束两个转动；轴向位置需另行保证。
- 圆孔：定位销、心轴；长短、间隙、锥度、端面接触会改变约束性质。不要只看“销”这个名称。
- 一面两孔：平面加圆柱销和削边销是常见组合。削边销释放两孔中心连线方向的重复约束，同时保留控制转角的约束；安装方向应配合这项功能。
- 辅助支承：工件先定位后才接触并锁定，用于提高局部刚度，不应把工件顶离原定位面。它与参与初始定位的自位支承不同（p.123）。

## 定位误差：沿工序尺寸方向求变动（p.129–133）

定位误差是工序基准在加工尺寸方向的最大变动量。分清：基准不重合误差来自工序基准与定位基准不同；基准位移误差来自定位副制造误差和配合间隙。

执行方法：

1. 明确加工尺寸方向及工序基准。
2. 画最大/最小工件及接触状态，保留同一工件尺寸在多个关系式中的相关性。
3. 建立工序基准相对刀具的位置函数。
4. 求该函数的极限差；不能把相互关联的两项一概绝对值相加，也不能一概相减。
5. 将定位误差纳入总误差预算，另计夹紧变形、导引/对刀、夹具安装和加工误差。

在理想对称V形块上，外圆轴线在对称面内，但直径变化会使中心高度变化。因此“自动对中”不等于所有方向零误差。以轴线、上母线、下母线作工序基准会得到不同的高度误差；需查p.130–131图5-24，不能套一个统一公式。孔轴间隙定位还需区分固定单边接触与任意边接触，半径偏移和全位置变动范围不是同一个量。

## 夹紧三要素（p.133–143）

**方向**：尽量指向主要定位支承，沿工件刚度较好的方向作用；结合切削力和重力，避免抬离定位面。

**作用点**：位于支承形成的稳定区域，落在刚性部位；尽量靠近加工处减少翻转力矩，但避让刀具和排屑。薄壁件优先扩大接触与合理布置支承。

**大小**：画完整受力图，分别检查滑移、翻转、旋转和接触压强；包含切削、重力、惯性等实际载荷。摩擦系数、传力效率与安全系数都要有依据。满足力平衡后还要检查弹性变形和松夹后的回弹。

| 机构 | 优势 | 主要取舍 |
|---|---|---|
| 斜楔 | 变向、扩力、可实现自锁 | 楔角小通常要更长行程；自锁取决于接触摩擦条件 |
| 螺旋 | 行程大、扩力和自锁性能较好 | 多圈操作慢，浮动压块有助避免带转工件 |
| 偏心 | 快速、紧凑 | 行程和扩力较小，自锁需验算，适用载荷受限 |
| 铰链/联动 | 动作快、多点夹紧 | 需均力和补偿尺寸差；不能假定各点天然等力 |
| 弹性定心 | 定心与夹紧结合 | 胀套/夹头变形、接触与工件壁厚必须匹配 |

## 演练：轴套径向钻铰孔（原书案例结构提炼）

p.144–146的案例要求轴套径向小孔对内孔轴线与端面保持位置关系。先用内孔和指定端面作为定位依据，再选择心轴及轴向压紧，利用快换钻套适应钻、铰两种刀具。

设计审核不止检查孔径：钻套轴线相对心轴的关系、心轴对夹具体安装面的关系、夹具与钻床连接、钻套更换重复性都要进入精度链。原图公差和尺寸需要回看扫描图，不能把OCR中的直径/对称度符号当最终图样。

## 设计交付顺序

输入零件和工序要求 → 比较定位/夹紧草图 → 定位误差与受力/变形检查 → 布置导引、排屑、操作空间 → 总图 → 非标件图与技术要求 → 检验及试切方案。通用、组合、可调和专用夹具按批量与产品稳定性选择，不用复杂程度证明设计价值。

自查：松夹前后尺寸有无变化？工件能否反装？基准面有毛刺时如何识别？切屑会否垫高？夹紧次序是否影响接触？与[ch06](ch06-machining-quality.md)、[ch07](ch07-process-planning.md)联用。
