# 第6章 机械加工质量

来源：印刷p.149–193 / PDF第159–203页。

## 核心判断

加工质量同时包括几何精度与表面层状态。先识别误差表现和变化规律，再寻找工艺系统中能产生该模式的原因；尺寸合格不能替代表面完整性评价。

## 建立误差地图（p.149–171）

先记录尺寸、形状、位置哪一项失效，以及误差沿工件位置、加工顺序、夹紧状态和温度如何变化。机床、刀具、夹具、工件及测量均纳入边界。

| 现象 | 优先假设 | 区分性检查 |
|---|---|---|
| 细长轴中间粗、两端细 | 切削力下工件弯曲 | 比较支承跨度、切深与跟刀架作用 |
| 薄壁孔夹紧时圆、松夹后失圆 | 夹紧弹性变形 | 分状态测量；改变夹紧力和接触分布 |
| 尺寸随加工件数单调漂移 | 刀具磨损或热漂移 | 记录刀具状态、时间和温度，换刀/冷却后复测 |
| 与回转周期相关的波纹 | 回转误差、传动力或不平衡 | 查频率/相位与转速的联系 |
| 余量不均被部分保留到成品 | 误差复映 | 比较毛坯误差与切后误差分布，检查受力刚度 |
| 一批数据双峰 | 不同机床、调整或材料混合 | 按来源和时间分层，不先假定单一正态 |

这些是诊断入口，不是一对一判定表。需用改变单一因素的对照或独立测量验证原因。

## 误差敏感方向与刚度

原始位移沿加工表面法线方向的分量通常最直接影响尺寸。对外圆车削的微小径向位移，直径变化可能约为其两倍；不能把任意空间位移都直接当成直径误差（p.151）。

检查各环节的柔度时，应统一载荷和位移方向。在线性、相同传力路径下，各部分变形可相加，柔度可相加；多支点、接触非线性和复杂载荷不能无条件套串联系统公式。最软环节往往主导结果，提高已经很硬的部件收益有限（p.156–163）。

缩短刀杆悬伸、增大截面、增加合理支承、减小径向力和均匀化余量常比仅降低转速有效。细长轴的支承、反拉切削及允许热伸长的尾座结构需要协调；把两端锁死可能造成热弯曲。

误差复映是毛坯误差导致切深/切削力变化，再经系统弹性变形保留一部分到成品。多次加工能减小这种误差，但不能代替对夹紧变形和内应力的处理。

## 热、内应力与振动（p.164–170）

热源分为内部切削/摩擦热与外部环境/辐射热。要管理温度分布、时间和相对位置，而非只看室温一个读数。预热、热源隔离、冷却、粗精分开和补偿分别作用于不同环节。教材中的预热时长和温度范围是历史示例，不是通用工艺参数。

去除材料会打破残余应力平衡；冷校直也可能留下不稳定应力。粗加工后重新定位、松夹释放和适当稳定化处理应结合材料与精度要求安排。不能只通过最后一次刀补解决随后还会变化的形状。

振动先区分强迫振动和自激振动。前者查不平衡、传动冲击、外部振源与共振；后者查切削反馈、系统动态刚度、刀具几何和切削条件。改变转速可能改变稳定性，但“越慢越稳”不成立。固定的所谓危险转速区间不能跨设备照搬。

## 统计诊断：分布图与点图（p.171–181）

1. 确认量具分辨率、测量方法和温度足以支持公差判断。
2. 按机床、刀具、材料和调整状态分层；保留加工顺序。
3. 用直方图观察中心、分散、偏态与多峰。直方图会丢掉时间信息。
4. 用顺序点图或均值—极差图判断趋势、突变及异常；合理分组，控制限由过程数据估计。
5. 过程稳定、分布与估计方法合理之后，再比较自然分散与规格公差。

教材工序能力系数以公差宽度与6σ比较。**控制限不是规格限**：过程稳定仍可能稳定地生产超差件，件件暂时合格也不保证过程受控。正态分布的±3σ约99.73%是模型概率，不是任何数据都能达到的承诺。

教学补充：现代常用Cp描述相对公差的分散能力，Cpk还考虑均值偏移；不要将教材分级表当作当前客户验收标准。控制图系数依子组大小选取，原书p.180表6-8的符号与现代软件可能不同，核对定义后再使用。

## 演练：能力与偏移（自编）

规格20.000±0.050mm，已确认稳定且近似正态，估计σ=0.010mm。公差宽0.100mm，6σ=0.060mm，Cp约1.67。若均值20.030mm，则上侧余量仅0.020mm，按现代Cpk定义得到min(0.020,0.080)/(3×0.010)≈0.67。

这说明分散小仍可能因中心偏移造成上侧风险。先判断偏移是否为可校正的常值误差；若均值一直变化，应先消除不稳定来源，不能将上述能力值当长期保证。

## 改善方法与表面完整性（p.181–191）

- 直接减小误差：修正几何精度、磨损、受力和温升。
- 误差转移：将影响转向非敏感方向或改由更可靠的基准保证。
- 误差分组：按尺寸/状态分类处理，降低组内变差。
- 就地加工：在实际装配关系中精加工，如现场修整卡爪；改善装夹关系不等于提高了主轴自身回转精度。
- 误差平均、补偿与主动控制：分别依赖相对运动、已知规律和在线测量反馈。补偿随机且不可观测的误差有边界。

表面质量应同时看粗糙度、纹理、冷作硬化、残余应力、组织变化和裂纹。降低进给或增大刀尖圆弧只改善几何残留的一部分；过小切厚会增加擦挤，较大圆弧也可能增加背向力与振动。磨削烧伤不能仅凭颜色判断，光磨去掉氧化色也可能仍留损伤层。选择砂轮、修整和冷却时同时评价粗糙度、热损伤与节拍。

审核输出：缺陷定义 → 数据与分层 → 机理假设 → 验证实验 → 改进措施 → 再测结果。避免在未确定机理时同时改动多个参数。关联[ch02](ch02-cutting-principles.md)、[ch05](ch05-fixtures.md)、[ch07](ch07-process-planning.md)。
