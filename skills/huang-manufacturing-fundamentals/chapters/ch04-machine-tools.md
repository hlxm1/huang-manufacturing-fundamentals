# 第4章 金属切削机床

来源：印刷p.79–117 / PDF第89–127页。型号、标准与设备案例属于2011年教材语境。

## 核心判断

选择机床要证明它能形成所需表面，并在工件尺寸、行程、精度、刚度、功率和生产节拍上满足要求。机床名字相同，并不意味着这些能力相同。将“能加工”与“能稳定经济地加工”分开判断。

## 从表面反推运动（p.84–86）

1. 识别发生线和导线：圆柱面、平面、螺旋面或齿面分别需要什么相对运动。
2. 判断成形方式：轨迹、成形刀具、相切或展成。成形刃承担一部分几何生成任务；展成依靠特定相对运动生成包络面。
3. 列出主运动、进给运动及切入、分度、让刀等辅助运动。不要把所有低速运动都叫进给。
4. 对复合成形运动，明确各运动分量之间的严格联系。内联系传动链保证相对关系，外联系传动链接入动力并调节速度。
5. 检查加工过程所需行程和退出空间。刀具能到达终点，还要能装卸、换刀和排屑。

为什么这样分析：一个回转加一个直线移动既可能车外圆，也可能车螺纹；差别在于两运动是否按导程严格同步。仅列运动数量不能说明成形原理。

## 传动链分析法：以CA6140为入口（p.87–94）

先确定首、末件，再沿传动路线记录每级传动副、变速/换向机构及连接条件，最后写运动平衡式。齿轮副的转速比应按主动、从动关系推导，不能机械地照抄图上齿数排列。

- 主运动链：电机到主轴，核算速度范围、级数和是否存在重复转速。
- 普通进给链：主轴或进给动力到刀架，核算每转进给及纵横向传动关系。
- 螺纹链：主轴转一转，刀架移动一个螺纹导程。多线螺纹中导程不等于螺距。
- 检查离合器、丝杠/光杠与换向机构的工作状态；一条路线在结构图上存在，不代表所有机构能同时接通。

原书各换挂轮、传动比和扩大螺距档位必须回看p.89–94传动图；本技能未把复杂齿数OCR作为计算数据。

## 工艺需求与设备映射

| 需求 | 首选考察对象 | 需要额外确认 |
|---|---|---|
| 轴、套、盘的回转表面 | 卧式/立式车床 | 工件重量、夹持方式、最大回转直径、床鞍干涉 |
| 平面、槽、轮廓 | 卧式/立式铣床、数控铣床 | 主轴方向、刀具可达性、夹具空间、间断切削刚度 |
| 淬硬表面或高精度尺寸 | 外圆、内圆、平面磨床 | 砂轮接触方式、修整、冷却、烧伤与测量 |
| 孔系尺寸及相互位置 | 镗床、坐标镗床、加工中心 | 重新建立孔轴线的能力、坐标精度及测量基准 |
| 大批通孔异形面 | 拉床 | 拉刀专用成本、额定拉力、行程和排屑条件 |
| 大型平面或机修工作 | 龙门刨床、牛头刨床等 | 往复运动惯性、空返行程、生产率 |
| 大批相似零件多孔加工 | 组合机床 | 专用多轴箱/夹具投资与产品变化风险 |

## 磨床与齿轮机床的分析重点

普通外圆磨床与万能外圆磨床的取舍是刚度、结构层次和工艺范围；“万能”不自动代表更高精度。无心磨削由砂轮、导轮和支承板共同控制工件，正确的支承几何和导轮作用是稳定加工的前提，不能理解为取消定位（p.99–103）。

成形法加工齿槽依靠刀具刃形；展成法依靠啮合关系。分析滚齿时先写刀具头数、工件齿数与相对回转关系，再考虑轴向进给；加工斜齿还要处理螺旋线引起的附加运动。插齿具有往复主运动、展成回转及让刀运动，适用范围应结合内外齿和相邻台阶干涉判断（p.103–107）。复杂差动链仍需查图。

## 数控机床与加工中心（p.107–110）

按控制介质/输入、数控装置、伺服驱动、机床本体和反馈链理解系统。反馈改善控制，但最终工件精度仍受热、受力、夹具及测量影响。加工中心通过自动换刀扩大一次装夹中的工艺集中程度；应核实轴数、回转工作台、刀库、主轴与工件姿态。不能仅凭“加工中心”推断所有侧面都可加工。

## 演练：箱体孔系方案（自编）

任务是加工顶面与侧面孔系，孔距和孔轴线对底面的位置有要求。先建立底面定位，比较：普通钻床逐孔找正、镗床坐标加工、加工中心集中加工。

逐项核对：已有孔能否作导向；孔位置错误是否需要镗削修正；侧孔需换装夹还是转台分度；翻面时基准如何传递；最深孔刀具伸出是否导致变形；批量是否能摊销专用夹具。结论应是带条件的设备和装夹方案，而非一句“用数控更准”。

## 易错点与复核

- 机床型号末位数字并非统一按同一比例表示尺寸；先识别机床类别和主参数定义（p.79–84）。
- 标称定位精度不能直接当作工件孔距公差的保证值。
- 拉床没有独立进给运动，不等于没有逐齿切厚；齿升量已布置在拉刀上。
- 只检查电机功率，遗漏低速扭矩、夹持力、刀具悬伸与工件动态平衡。
