# 第三章：金属切削刀具

定位：印刷页49–78；PDF第59–88页。选型依据：p.49–53、57–68、70–78。

## 核心判断

由工件材料和状态、表面特征、工序性质、设备与批量共同选刀；把刀片材料、槽型、刀杆、夹持和冷却视为一套系统。较硬的刀具材料不自动意味着更适合冲击切削。

## 材料选择框架（p.49–53）

检查硬度与耐磨性、强度与韧性、耐热性、导热和抗热冲击、制造工艺性与经济性。连续高速精加工和带硬皮的断续粗加工，其主导约束通常不同。

| 材料类别 | 可优先评估的场景 | 需要核查的代价 |
|---|---|---|
| 高速钢 | 复杂刃形、低中速、需要韧性的刀具 | 热硬性限制切削速度 |
| 硬质合金 | 多数车、镗、铣等加工 | 材料牌号与冲击、磨损机理匹配 |
| 涂层刀具 | 兼顾基体韧性与表面耐磨性 | 涂层、基体及刃口处理共同影响适用范围 |
| 陶瓷 | 刚性与稳定性良好的适宜高速加工 | 脆性、断续冲击与热冲击 |
| 金刚石/PCD | 有色金属及适合的非金属、复合材料 | 通常不用于常规铁族材料切削，化学磨损可能显著 |
| CBN/PCBN | 淬硬钢、冷硬铸铁等适宜材料 | 工件硬度、连续性、含量和结合剂须对应具体牌号 |

原书以YG/YT/YW及K/P/M说明硬质合金分类，是认识性能取舍的入口；现代产品适用组和牌号必须查厂家资料，不能把历史对照表当成所有涂层、超细晶产品的一一等价关系。

## 结构与刃形（p.53–61）

整体、焊接、机夹和可转位结构，体现重磨、换刃、制造成本及重复定位的不同取舍。可转位刀具便于稳定几何和快速更换，但刀片定位面、刀垫、夹紧与刀杆刚度仍影响实际表现。

成形车刀、成形铣刀以专用刃形获得轮廓，适于重复生产；刀具刃形一般不能直接照抄工件截形，因为前后角、安装与测量截面会引入转换。定制时应列出工件坐标、刀具结构、前后角与允许误差，按专门设计方法计算。

### 顺铣与逆铣的选择

1. 先在接触点比较刀齿切削速度与工件进给方向，判定顺铣或逆铣；不要只看主轴转向。
2. 顺铣通常从较大切屑厚度切入、逐渐减小，逆铣则相反。逆铣的初期滑擦和顺铣的切入冲击需分别评价。
3. 检查进给传动间隙与防窜动能力。旧式有间隙传动顺铣时可能被切削力拉动，不能机械套用数控机床习惯。
4. 再看硬皮、装夹、刀具韧性、热冲击、跳动、排屑以及表面要求。端铣还须区分对称、不对称顺铣和不对称逆铣。

刀齿增多可能提高切削刃总长度，却减少容屑空间；过大跳动会造成各齿负荷不均。粗齿/细齿、螺旋角、分屑槽都应围绕负荷和排屑选择。

## 孔加工刀具：先问要修正什么（p.61–68）

| 工序 | 主要任务 | 不能默认解决的问题 |
|---|---|---|
| 中心钻或适当引导工序 | 建立起钻/中心支承条件 | 后续孔的全部位置与方向精度 |
| 钻孔 | 从实体形成孔 | 高精度孔径、直线度和位置 |
| 扩孔 | 扩大已有孔、改善预加工状态 | 代替所有孔系精度保证措施 |
| 锪削 | 沉孔、锥形沉孔或端面座面 | 独立纠正原孔轴线 |
| 铰孔 | 小余量改善孔径和表面质量 | 大幅修正原孔位置和轴线偏斜 |
| 镗孔 | 以机床运动建立或修正孔径及位置关系 | 消除细长镗杆挠曲与热误差 |

麻花钻外缘与钻芯附近的前角不同，横刃处切削条件较差，轴向力和定心能力需关注。深孔加工把导向、断屑、排屑、润滑冷却列为一体，不应只用更长的普通钻头替代深孔工艺。

铰刀是定尺寸刀具，直径设计还涉及制造公差、磨损储备以及孔的扩张或收缩。齿数、槽形、倒锥和切削余量均有作用；本技能未逐项核验p.67–68的铰刀极限尺寸公式，定制时必须查原页和刀具手册。

## 复杂刀具（p.68–78）

- **螺纹刀具**：车刀适应性强；丝锥、板牙按内外螺纹和生产要求选用；滚丝轮、搓丝板属于塑性成形，还受材料塑性与径向承载约束。
- **拉刀**：沿刀长分布的齿升量实现逐步去除，切削部、校准部及前后导向各有作用。选型时同时检查拉力、刀长、容屑、孔是否贯通、退刀和批量摊销。
- **成形齿轮刀具**：刃形与齿槽对应，设备可较简单，但精度和通用性受限。
- **展成齿轮刀具**：用相对运动包络齿廓。选择滚刀、插齿刀等时核对模数、压力角、齿制、旋向、精度和机床运动条件。相同模数还不足以保证通用；滚刀不能无条件加工任意内齿或受肩部干涉的齿轮。

## 方法练习：孔径合格但位置超差

依据本章孔加工方法自编，非原书例题。某支架孔钻后偏向一侧，铰削后孔径和粗糙度合格，孔位仍超差。

1. 不再把铰刀直径加大作为孔位修正手段；先检查基准、钻套导向、刀具偏摆和初始孔偏斜。
2. 若剩余材料与设备能力允许，用相对正确基准的镗削重新建立孔轴线，然后完成精加工；余量不足时不能宣称可修复。
3. 工艺卡同时列孔径、位置要求、测量基准和验证方法，防止只检验孔径。

## 误区与自查

- 把“定尺寸刀具”理解为实际加工尺寸恒等于刀具名义尺寸。
- 把齿数增加等同于效率必升，忽略排屑和跳动。
- 用成形刀具照搬工件轮廓，忽略角度与安装转换。
- 只按材料大类选刀，未说明热处理状态和切削连续性。

自查：刀具清单是否能回答“加工什么表面、修正什么误差、由谁导向、如何排屑”？
