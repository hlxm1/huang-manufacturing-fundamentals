# 九章学习与练习路径

建议先走通1→2→3→4→5→6→7→8，再用9扩展方法边界。每次学习都产出一个可检查的结果；不以复述术语代替应用。

| 章 | 学习产物 | 自查/通过标准 |
|---|---|---|
| 1 | 一张生产与工艺过程关系图；一次纲领计算 | 能区分纲领、批量；废品率口径明确 |
| 2 | 一份车削参数换算；一个磨损/热问题因果图 | 单位与实际档位复算正确；能解释参数取舍 |
| 3 | 两种刀具材料及孔加工路线比较 | 说明材料状态、刚韧性及能否修正孔位 |
| 4 | 表面→成形运动→传动链示意 | 能说明运动联系而不凭空编齿数或传动比 |
| 5 | 定位自由度表及夹紧力流 | 不完全定位与欠定位分清，支承可承载 |
| 6 | 尺寸按时间记录图及辨别试验 | 分清稳定与能力、随机与趋势；诊断有反证 |
| 7 | 带基准、余量、尺寸和检验的工艺路线 | 对一次基准转换完成极值尺寸链计算 |
| 8 | 装配单元图及两种精度保证方案 | 计算游隙极限；调整方向/范围均可行 |
| 9 | 三种加工方法的淘汰与推荐表 | 判断导电性、热影响、表层与总成本 |

## 综合练习（自编）

对象：一根支承轴、配套箱体及齿轮构成的小型传动部件。材料、尺寸、精度和数量由学习者明确给定，未知值保留空白。

1. 识别主要配合和相互位置要求，将其分配到零件加工与装配验收。
2. 分别制定轴与箱体的基准及路线，解释热处理/时效安排。
3. 选一个工序建立定位自由度表，推演夹紧变形风险。
4. 对一个车削工序换算n、vf、Pc，检查机床能力。
5. 建立轴向游隙链，先按完全互换计算，再比较调整方案。
6. 为热漂移、孔位偏差或振纹设计区分原因的测量。
7. 比较通用装备与专用方案在两种产量下的费用和柔性。

评价：功能要求是否闭合？每个参数是否有来源？每个计算是否说明保证方式？最终能否执行和测量？

## 推荐对话

- “用第5章方法检查我的定位方案，逐项解释自由度与受力。”
- “按第7章检查这份工艺路线，先指出缺少哪些会改变结论的数据。”
- “用第8章极值法校验这条游隙链，并比较分组与调整方案。”
- “讲解第6章误差复映，给自编例子并列出适用条件与原书页码。”

答题顺序采用：先自行推导→与章节核对→必要时查原扫描页→记录差异。复杂图表题必须查看用户自备原页，不能只依靠OCR还原图样。
