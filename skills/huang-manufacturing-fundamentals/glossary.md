# 术语表

定义为教学提炼；页码由章节索引定位，不代替原书完整论述。

| 术语 | 操作性定义/区别 | 章 |
|---|---|---|
| 生产过程 | 从原料到成品的全部活动，含加工以外的运输、检验等 | 1 |
| 工艺过程 | 改变对象形状、尺寸、相对位置或性质等的过程 | 1、7 |
| 工艺系统 | 机床、刀具、夹具和工件组成的相互作用系统 | 1、6 |
| 生产纲领 | 规定期间应生产的合格产品/零件数量 | 1 |
| 批量 | 同一批投入生产的相同产品或零件数量，区别于年产量 | 1 |
| 主运动/进给运动 | 主要形成切削速度的运动/使切削得以继续的运动 | 2、4 |
| 切削速度vc | 切削刃选定点相对工件的主运动瞬时速度 | 2 |
| 进给量f/每齿进给fz | 每转或每行程的位移/每一齿承担的进给 | 2、3 |
| 背吃刀量ap | 待加工面与已加工面间按规定方向量取的切削层尺寸 | 2 |
| 前角/后角 | 刀具前面/后面相对参考平面的角度，须明确测量平面 | 2 |
| 工作角度 | 加工运动与安装条件下的刀具实际角度，区别于标注角度 | 2 |
| 积屑瘤 | 一定条件下切屑材料黏附并堆积于刃口附近的硬化体 | 2 |
| 刀具寿命 | 达到规定磨钝标准前的实际切削时间，不是日历时间 | 2 |
| 加工硬化 | 表层塑性变形引起硬度、强度等变化；不是淬火 | 2、6 |
| 磨料硬度/砂轮硬度 | 前者属磨粒材料，后者反映结合剂保持磨粒的能力 | 2 |
| 整形/修锐 | 恢复砂轮几何形状/恢复有效切削刃与容屑能力 | 2、9 |
| 顺铣/逆铣 | 接触处切削速度方向与工件进给同向/反向 | 3 |
| 成形法/展成法 | 用刀刃轮廓直接形成表面/用刀具工件的共轭运动包络形成表面 | 3、4、7 |
| 传动链 | 为实现规定运动联系而连接执行件与运动源的传动系统 | 4 |
| 定位/夹紧 | 确定所需位置/保持其在外力作用下的位置 | 5 |
| 不完全定位 | 根据工序要求合理保留部分自由度 | 5 |
| 欠定位 | 应限制的自由度没有受到可靠限制 | 5 |
| 过定位 | 多个定位约束重复限制同一自由度；可能引入矛盾 | 5 |
| 定位误差 | 定位引起工序基准沿所研究方向的位置变动 | 5 |
| 基准不重合/基准位移 | 设计或工序基准与定位基准不同引起的影响/定位副间隙或几何变动引起的影响 | 5、7 |
| 原始误差 | 工艺系统中引起加工误差的各种初始因素 | 6 |
| 误差复映 | 毛坯等误差经切削力和系统变形传入加工结果的现象 | 6 |
| 系统刚度 | 指定方向的力与对应弹性位移之比 | 6 |
| 强迫振动/自激振动 | 外部周期激励维持的振动/切削过程反馈维持的振动 | 6 |
| 控制界限/规格界限 | 过程统计行为的判断界限/产品设计验收界限 | 6 |
| Cp | 在稳定且模型适用时，以公差宽度对比过程分散的指数，未体现均值偏移 | 6 |
| 表面质量 | 表面几何特征及表层物理力学状态的综合 | 6 |
| 粗基准/精基准 | 未加工表面/已加工表面作为定位基准 | 7 |
| 工序/安装/工位 | 工作地连续完成的过程单元/一次装夹/安装后占据的加工位置 | 7 |
| 工步/走刀 | 按表面、刀具和条件等划分的工序部分/一次切除行程 | 7 |
| 加工经济精度 | 正常条件下能以合理成本达到的精度范围 | 7 |
| 工序余量/总余量 | 相邻工序间应切除的材料层/毛坯到成品所需切除材料层 | 7 |
| 封闭环 | 由组成环间接形成、需要保证的尺寸或关系 | 7、8 |
| 增环/减环 | 自身增大使封闭环增大/减小的组成环 | 7、8 |
| 极值法/概率法 | 根据极端组合保证范围/根据统计假设推算分布的尺寸链方法 | 7、8 |
| 完全互换/大数互换 | 任意合格件组合满足装配要求/统计意义下绝大多数组合满足 | 8 |
| 修配/调整 | 去除预留材料补偿累积误差/改变调整件尺寸或位置补偿误差 | 8 |
| 微细加工/超精密加工 | 侧重对象特征尺寸很小/侧重加工误差及表面质量很高 | 9 |
| 电火花/电解加工 | 脉冲放电热蚀除/阳极电化学溶解，均须满足各自导电等条件 | 9 |
| CAD/CAPP/CAM | 计算机辅助设计/工艺过程设计/制造 | 9 |
| FMS/CIMS | 柔性制造系统/计算机集成制造系统，后者强调更广的信息与业务集成 | 9 |
| 绿色制造 | 将资源消耗及环境影响纳入产品制造及生命周期决策 | 9 |
